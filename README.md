# 雷霆戰機3D · Thunder Striker 3D

向經典街機《雷電》致敬的 3D 縱向捲軸射擊遊戲。Three.js 全 3D 建模：立體戰機、景深地面、粒子爆破、鏡頭震動。

🎮 **線上遊玩**：https://hebe2234.github.io/thunder-striker-3d/

## 玩法

- **操作**：滑鼠 / 手指拖曳移動（自動開火）、空白鍵 / X 炸彈、P 暫停、M 靜音
- **三種主武器**（吃 R / B / P 切換，Ⓟ 升級，滿級 8 級）：
  - 🔴 火神散射炮 VULCAN — 7 向扇形彈幕＋雙側炮，雜魚殺手
  - 🔵 雷射光束 LASER — 持續高貫穿傷害，滿級三束齊發，BOSS 剋星
  - 🟣 電漿爆裂彈 PLASMA — 重型電漿球＋範圍爆炸，清場神器
- **飛彈**：M 追蹤飛彈（自動鎖定）/ H 燃燒飛彈（範圍燃燒）
- **炸彈**：全螢幕衝擊波＋短暫無敵
- **3 個關卡**：黃昏都市 → 沙漠風暴 → 午夜要塞，含中 BOSS「鐵鷲」與最終 BOSS「暴風要塞」（三階段）
- 通關後進入下一輪，敵軍全面強化；最高分保存在本機

## 本機開發

直接用靜態伺服器開啟即可（需連網載入 Three.js CDN）：

```bash
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```

## 技術

- Three.js（CDN）程序化低多邊形建模，無外部素材
- WebAudio 全程式合成音效＋背景音樂
- 物件池（子彈 / 粒子）＋包圍體碰撞，手機也能順跑
